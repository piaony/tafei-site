# 签名钥匙说明

`hobby-key.b64` 是 base64 编码的签名密钥（PKCS12）：

- 别名：`androiddebugkey`
- 密码：`android`
- 指纹：`3C:84:B3:46:AF:CC:27:3D:27:9D:DF:4F:18:88:1A:38:07:C4:1C:58:E1:83:50:15:D9:66:B4:0F:9D:88:8C:66`

## 为什么要放在仓库里

安卓只认“同一个签名”才能覆盖升级。放在这里是为了不需要配置 GitHub Secret（手机 App 里没有这个入口），每次构建都用同一把钥匙，版本能升上去。

## 代价

钥匙是公开的：任何人拿到它都能做一个“看起来是官方升级包”的 APK。所以它只适合自用 / 小范围分发的测试包（本身就不代表“这是官方发的”）。

## 以后想变正规

在仓库 Settings → 机密和变量 → 操作 里加 `ANDROID_KEYSTORE_B64`（正式密钥），workflow 会优先用它。注意：密钥一换，签名就变了，已装的旧版必须先卸载才能装新版（一次性的）。
